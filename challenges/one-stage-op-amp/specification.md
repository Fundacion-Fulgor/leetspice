# One-Stage Operational Amplifier

Design and optimize an IHP SG13G2 one-stage operational amplifier across server-owned checks.

Submit exactly one `.subckt one_stage_op_amp inp inn out vdd vss` using SG13G2 low-voltage MOS devices, resistors, and capacitors. Server-owned profile checks enforce circuit-family structure, device mix, and sizing bounds. Fewer devices and smaller total gate width improve score after all hard limits pass.
