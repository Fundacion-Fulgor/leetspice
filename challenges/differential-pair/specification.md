# Differential Pair

Design and optimize an IHP SG13G2 differential pair across server-owned checks.

Submit exactly one `.subckt differential_pair inp inn outp outn vdd vss` using SG13G2 low-voltage MOS devices, resistors, and capacitors. Server-owned profile checks enforce circuit-family structure, device mix, and sizing bounds. Fewer devices and smaller total gate width improve score after all hard limits pass.
