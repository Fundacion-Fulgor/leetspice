# MOS gm/ID Explorer

Design and optimize an IHP SG13G2 mos gm/id explorer across server-owned checks.

Submit exactly one `.subckt mos_gmid d g s b` using SG13G2 low-voltage MOS devices, resistors, and capacitors. Server-owned profile checks enforce circuit-family structure, device mix, and sizing bounds. Fewer devices and smaller total gate width improve score after all hard limits pass.
