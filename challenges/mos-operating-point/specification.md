# MOS Operating Point

Design and optimize an IHP SG13G2 mos operating point across server-owned checks.

Submit exactly one `.subckt mos_operating_point d g s b` using SG13G2 low-voltage MOS devices, resistors, and capacitors. Server-owned profile checks enforce circuit-family structure, device mix, and sizing bounds. Fewer devices and smaller total gate width improve score after all hard limits pass.
